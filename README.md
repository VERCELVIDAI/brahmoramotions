## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Interactive 3D:** Three.js with pointer parallax, polyhedral core, orbiting panels, particle system, and responsive fallback
- **Icons:** Lucide React
- **Confetti:** Canvas Confetti
